# Zunsports Invoice Maker

A fast, professional invoice generator for Zunsports — inspired by the clean
layout of big-company invoices (header with logo, bill-to block, itemised
table, bold total, advance & balance tracking).

## Features
- Fill the form on the left — the invoice updates live on the right
- Items with quantity × unit price, automatic amounts
- Discount %, tax %, shipping, advance paid → balance due
- Currencies: USD, EUR, GBP, PKR
- Print / Save as PDF (clean A4 sheet, editor hidden when printing)
- Save invoices in the browser and reload them later
- One-click sample: the Solejunky 40-piece order (25% first-order discount)

## Use
Open the GitHub Pages site, fill in the customer and items, then
**Print / Save PDF** and send the PDF to the customer.
